Comparison on a mesh with thin separated parts.

Every method on an object whose parts are thin and separated. The baselines that build their own geometry lose the leaves, so their effect is carried on a shape that is no longer the input one, whereas our method changes only appearance and keeps the underlying geometry the same.

Continuing an effect across clips.

A second reference video, generated from the last frame of the first, continues the same effect, so a progression that does not fit in one clip can be carried across several. The cracks spread over the metal unicorn in the first clip and heat to glowing amber in the second.
